# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for tic-tac-toe.

## Rules

1. Use `NNNN-short-title.md` names with four-digit numbers.
2. New ADRs start as `Proposed`.
3. `Accepted` ADRs are immutable. If a decision changes, create a superseding ADR rather than editing the accepted record.
4. Architectural PRs must add or update a Proposed ADR before merge.
5. Reviews must check the decision, evidence, trade-offs, and consequences — not merely the presence of a file.
